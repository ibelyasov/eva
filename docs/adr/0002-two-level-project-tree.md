# Два уровня проектов, ниже — Разделы

Владелец держит в SingularityApp десятки мелких проектов и просит «подпроект в нём», когда хочет разделить дело на части. SingularityApp позволяет вкладывать проекты на любую глубину и отдельно даёт Разделы (`task_group`) внутри проекта.

Дерево Eva — два уровня проектов: Область — проект верхнего уровня, Проект — проект прямо в ней. Всё, что ниже Проекта, — Раздел: просьбу «подпроект», «вложенный проект» в Проекте и «добавь проект X в проект Y» Eva выполняет `task_group_create`, а не `project_create`, и разницу владельцу не объясняет; такая просьба в Области создаёт Проект. У Области тоже могут быть Разделы — для одиночных задач. Тип объекта определяется только по положению в дереве; пометок, служебных тегов и записей в Журнале для него нет. Активный Режим поддерева назначается Области, `когда-нибудь` — Области или отдельному Проекту ([ADR 0006](0006-state-in-eva-journal.md)).

У каждого Проекта — эмодзи по смыслу, у каждой Области — один цвет, который получают её Проекты. Их выбирает Eva при создании как часть явной команды, без отдельного согласия; существующие объекты без эмодзи и цвета она предлагает дополнить одним Preview ([ADR 0014](0014-confirmations.md)).

## Considered Options

- Произвольная глубина с промежуточным типом для проекта с дочерними проектами: тип зависит от состава потомков, крупное дело теряет свой Следующий шаг, а режимы и обзор приходится разбирать по нескольким уровням.
- Отметка типа в Журнале или служебный тег: состояние расходится с деревом в приложении и засоряет пространство владельца.
- Объяснять владельцу, что «подпроект» станет Разделом: лишний ход ради различия, которое ему не нужно.
- Цвет на каждый Проект: цветом в списке различаются контексты жизни, а не отдельные дела; пёстрый список не помогает выбору.

## Consequences

Существующий проект глубже второго уровня до превращения считается Разделом своего Проекта второго уровня; Eva одним Preview предлагает превратить его в Раздел с переносом Задач и архивом пустого проекта. Части дела с отдельным обзором и собственным Следующим шагом Eva сама предлагает отдельными Проектами той же Области. `color` — hex `#RRGGBB`, как задаёт описание поля в `project_create`. Как эмодзи и цвет отображаются в приложении, живьём не проверено.
