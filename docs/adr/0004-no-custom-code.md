# Никакого собственного кода

Репозиторий содержит только инструкции скиллов, `skills/*/tools.json` и документы. `tools.json` — декларативные данные внешнего контракта с Hermes, а не код. MCP-декларации и инфраструктура модельных проверок в пакет не входят. Проверки — `git diff --check` и независимое ревью агентом; модельных прогонов нет. Штатной проверки frontmatter, security scan и discovery для каталога `skills.external_dirs` у Hermes нет, поэтому эти свойства проверяет ревью ([ADR 0017](0017-declarative-preferences.md)). Собственный сборщик, валидатор, fake MCP или replay-проверки проверяли бы сами себя и неоправданно усложняли пакет инструкций. Новый код появляется только если конкретную проверку нечем закрыть штатно, и только после отдельного решения.
