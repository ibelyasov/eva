# Привычка и проект у провайдера ссылаются на свою Заметку

Заметка о привычке `Жизнь/Мои привычки/<Привычка>.md` хранит знания и «зачем мне» словами владельца; Заметка о проекте `Проекты/<Проект>.md` или `Работа/Проекты/<Проект>.md` — материалы, контекст и решения. План эксперимента, даты, отметки, статус проекта и задачи остаются у провайдеров и в Хранилище не дублируются. Владелец открывает привычку в Habitify или проект в SingularityApp и хочет перейти к знаниям о нём.

Связь двусторонняя. В Заметке — `habitify_id` или `singularity_id`: `jedikit-notes` читает ID через скилл-владелец; не найден — поле пустое, а в Отчёте отметка. `provider_url` записывается, только если ссылку вернул провайдер; из ID она не конструируется. У провайдера — обратная ссылка: при создании Заметки о привычке или о проекте как части просьбы владельца в описание привычки Habitify или заметку проекта SingularityApp дописывается строка `Obsidian: <путь без .md>` и, если задан `jedikit.notes.vault_name`, URI `obsidian://open?vault=<имя>&file=<путь без .md>` с percent-encoding значений. Существующий текст сохраняется. Запись выполняет скилл-владелец — `jedikit-habits` или `jedikit-tasks` — по своему `references/write-policy.md` с Read-back ([ADR 0012](0012-skill-composition.md)); в Отчёте она отдельной строкой. Сам `jedikit-notes` в провайдеры не пишет. При `jedikit.habits.names = neutral`, а для чувствительной привычки и при незаданном ключе, обратная ссылка в Habitify не пишется: путь Заметки раскрыл бы тему, которую скрывает нейтральное название, а описание видно в Habitify; в Отчёте одна строка — почему и как владелец может добавить строку сам. Для существующих привычек и проектов массовой простановки нет.

## Considered Options

- Односторонняя связь, только ID в Заметке: из приложения провайдера к знаниям не перейти.
- Поле `obsidian_url` во frontmatter Заметки: имя Хранилища и путь уже известны, а при переименовании поле устареет.
- `obsidian://open?path=<абсолютный путь>`: путь различается на Mac и Android. `open?file=` без `vault` не гарантирует хранилище по умолчанию; ID хранилища привязан к папке на конкретном компьютере. Имя хранилища одинаково на устройствах.
- Запись обратной ссылки из `jedikit-notes` напрямую: две политики записи одного провайдера ([ADR 0012](0012-skill-composition.md)).
- Массовая простановка для существующих объектов: пачка записей в провайдеры без просьбы владельца.

## Consequences

Без `jedikit.notes.vault_name` обратная ссылка — только читаемый путь. Открывается ли `obsidian://` из описания Habitify и заметки проекта SingularityApp на Mac и Android, не проверено. При перемещении или переименовании Заметки внутренние ссылки Obsidian обновляет, а строку у провайдера — нет: её исправляют отдельной просьбой. Основание формата URI и полей — [досье полей](../../research/notes/fields.md).
