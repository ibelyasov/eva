# Захват

Захват сохраняет присланное из Telegram без разбора. Поля — [fields.md](fields.md), проверка и Отчёт — [write-policy.md](write-policy.md#проверка-и-отчёт).

## Запиши

«Запиши …» обычными словами, без обязательных префиксов: место выбирает агент по смыслу и сообщает одной строкой, что и куда записал; владелец поправит словами.

| Что записать | Куда |
| --- | --- |
| Обязательство или действие | `jedikit-tasks`: Capture во Inbox SingularityApp |
| Идея: возможность, «когда-нибудь подумать о…», без обязательства | Строка с `#идея` в заметке дня ([journal.md](journal.md#идеи)) |
| Мысль, наблюдение, запись о дне | Заметка дня ([journal.md](journal.md)) |
| Ссылка, пост, файл, «сохрани в базу», справка | Захват: источник в `Источники/…` или адресная заметка домена; Входящие хранилища — если адрес неясен или захват не удался |
| Неясно, задача это или мысль | `jedikit-tasks`: Inbox SingularityApp, Triage разберёт |

- Передача `jedikit-tasks`: загрузи `skill_view(name="jedikit-tasks")` и его `references/write-policy.md`, запись ведёт он. Недоступен — назови это; в Хранилище задачу не записывай.
- Несколько записей в одном сообщении — каждую по таблице, последовательно, стоп на первой ошибке.
- Приоритет выбора: явное указание места → подпись к вложению → смысл → тип файла. Префиксы `дневник:`, `входящие:`, `сохрани:` — договорённость, не команды Hermes; если владелец их пишет, они задают место.

## Тип входа

| Вход | Что делать | Чего не делать |
| --- | --- | --- |
| Голая ссылка | [Ссылка](#ссылка): источник в домене поступления | Не считать прочитанной владельцем, не разбирать |
| Пересланный пост | Источник с `origin: source`, известная атрибуция в теле; ссылки поста — по просьбе | Не выдавать за слова владельца, автора не угадывать |
| Своя мысль, событие | Заметка дня; при явном адресе — туда | Не улучшать текст, не делать из состояния общий факт |
| Комментарий к привычке, проекту, курсу | Секция «Комментарии владельца» этой заметки; адресат неоднозначен — Входящие хранилища | Не дописывать мотивацию, не менять провайдера |
| PDF, документ, фото материала | [Файл](#файл) | Не заявлять OCR, чтение или понимание |
| Своё фото к записи дня | `Вложения/` и вставка `![[…]]` в строку заметки дня | — |
| Прямой вопрос | Ответ по [wiki.md](wiki.md#вопрос) | Не захватывать, не сохранять ответ без просьбы |
| Видео | Не захватывается; ссылку по просьбе — во Входящие хранилища | Не извлекать |
| Пейволл, вход по логину | Сохранить доступное с `capture: partial`; полный текст присылает владелец | Не обходить |

Домен поступления: общий — `Источники/…`; рабочий — `Работа/Источники/`; курс — `Обучение/<Курс>/Источники/`; сообщество — `Сообщества/<Сообщество>/Источники/`. Адрес неясен — общий.

## Ссылка

1. Вызови `web_extract`. Сбой, пустой ответ или нет инструмента — [сбой](#сбой).
2. Найди источник с тем же `source_url` (`search_files` по `source_url:`). Есть — сначала [повтор](#повтор).
3. Путь — `<Источники домена>/Статьи/<Заголовок>.md` (у научной публикации — `Публикации/`, у расшифровки — `Транскрипты/`; в доменных `Источники/` без подпапок). Имя — по [правилу имён](fields.md#имена-файлов-и-папок). Проверь, что путь свободен; занят другим материалом — суффикс даты захвата по [без перезаписи](write-policy.md#без-перезаписи): `<Заголовок> (ГГГГ-ММ-ДД).md`.
4. Ответ с подвалом `[TRUNCATED]` и строкой `Full text saved to: <путь>` — сразу запиши frontmatter `write_file`, затем допиши тело из файла кэша в `terminal`: `cat "<кэш>" >> "<заметка>"`. Перед этим проверь конец файла кэша (`tail -c 400 "<кэш>"`): пометка `stored copy truncated` там значит `capture: partial`. Без подвала — ответ полный: запиши frontmatter и тело `write_file`.
5. Посчитай `sha256` тела по [tools.md](tools.md#sha256) и впиши его `patch` вместо пустого значения `sha256: ""`.
6. `capture: full` — полный доступный Markdown, картинки удалёнными ссылками. `capture: partial` — сохранён фрагмент (пейволл, усечённая копия, полный текст не сохранён); причину напиши первой строкой тела.
7. Проверка `read_file` (frontmatter и начало тела) и одна строка Отчёта: «Сохранено в <путь>: полный доступный Markdown, картинки — удалённые ссылки. Разбор не выполнялся.»

Тело источника — только извлечённый текст, без выводов агента. Картинки не скачивай. Полную копию с локальными картинками не делай, пока в `tools.json` нет инструмента полного захвата.

## Файл

1. Имя — по подписи или исходному имени файла, по-русски, по [правилу имён](fields.md#имена-файлов-и-папок). Проверь, что свободны и `<Имя>.<ext>`, и `<Имя>.md` (`test -e` в `terminal`); занято — суффикс даты захвата по [без перезаписи](write-policy.md#без-перезаписи).
2. Скопируй вложение из кэша Hermes в `terminal` без перезаписи: `cp -n "<кэш>" "<Источники домена>/Файлы/<Имя>.<ext>"`, затем сверь `sha256sum` копии с кэшем; не совпало — стоп, «не сделано».
3. Рядом создай заметку `<Имя>.md`: `type: source`, `origin: source`, `sha256` байтов файла (`sha256sum "<файл>"`), `captured_at`, `ingested`, `capture: full`; в теле — вставка `![[<Имя>.<ext>]]` и подпись владельца как есть.
4. Файл не распознавай, не извлекай текст и не пересказывай; чтение и OCR — только отдельной просьбой.
5. Проверка `read_file` заметки и наличия файла (`search_files`), одна строка Отчёта.

## Повтор

1. Если `sha256` нового тела известен до записи (файл кэша или вложение) и равен сохранённому — новый файл не пиши, ответь: «Уже сохранено: <путь>».
2. Иначе сравни нормализованный текст нового извлечения с телом сохранённого: игнорируй различия пробелов и пустых строк вне блоков кода и одноразовые параметры у ссылок на картинки (подписи, размеры, cache-busters). Длинные тела сравни `diff` в `terminal` и оцени, все ли отличия такого рода.
3. Совпало — новый файл не пиши. Отличается — новая версия рядом с датой захвата в имени, старая не трогается; в теле новой — ссылка на прежнюю.

Редкие лишние версии допустимы: стабильный Markdown провайдер не гарантирует.

## Сбой

Если `web_extract` недоступен, вернул ошибку или пустой текст, создай `Входящие/<Заголовок или домен> (ГГГГ-ММ-ДД).md` (имя — по [правилу имён](fields.md#имена-файлов-и-папок), путь свободен): `type: inbox`, `origin: source`, `received_at`, `channel: telegram`, `source_url`, `capture: failed`, без `sha256`; в теле — ссылка и подпись владельца как есть. Источник не создавай, другого провайдера не подставляй.

```text
Не удалось извлечь текст по <URL>. Ссылка сохранена во Входящих: <путь>.
Полная копия не получена; разбор не выполнялся.
```

## Входящие хранилища

`Входящие/` (и `Работа/Входящие/`) — место для материала с неясным адресатом или типом и для неудачного захвата. Заметка — `type: inbox` по [fields.md](fields.md). Разбор Входящих начинает владелец; автоматической обработки, сроков и ежедневных вопросов нет. Перенос из Входящих — по просьбе, с проверкой каждой записи.

## Передача от `jedikit-tasks`

При Triage `jedikit-tasks` передаёт текст Inbox item, его ID и дату создания в `jedikit.timezone`. Даты нет — блокирующий пробел для Идеи.

- Идея — строка с `#идея` в заметке дня за дату создания Inbox item ([journal.md](journal.md#идеи)).
- Справка — захватом: ссылка или файл — источник в `Источники/…`, текст — адресная заметка домена, если адресат однозначен; иначе Входящие хранилища (`channel: singularity`).
- Верни путь и результат проверки `read_file`. Inbox item отменяет `jedikit-tasks` и только после подтверждённой записи; сам SingularityApp не трогай.
