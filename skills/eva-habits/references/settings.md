# Предпочтения, Пометки Ритуалов, status и фоновый запуск

Записи в Habitify и в Журнал Eva — по [write-policy.md](write-policy.md).

## Предпочтения

Предпочтения задаёт Потребитель — сторона, которая подключает Eva к Hermes, — в конфигурации Хоста. Скилл их только читает и никуда не записывает: ни в Журнал Eva, ни в файлы скиллов.

Значения Hermes добавляет к загруженному навигатору `eva` блоком такого вида:

```text
[Skill config (from ~/.hermes/config.yaml):
  eva.timezone = Europe/Moscow
  eva.habits.names = (not set)
]
```

Этот скилл читает два ключа:

| Ключ | Значение | Если не задан |
| --- | --- | --- |
| `eva.timezone` | IANA timezone, например `Europe/Moscow`: «сегодня», относительные даты, даты Отметок, статистики и обзора | Спроси, когда сценарию нужна дата |
| `eva.habits.names` | `exact` — точные названия; `neutral` — нейтральные для чувствительных тем. Задаёт, как назвать привычку в Habitify и в обратной ссылке; сообщения Eva называют привычку её названием в Habitify | Спроси при создании чувствительной привычки ([Названия](#названия)) |

- Не задано — значение `(not set)` или ключа нет в блоке. Нет блока в контексте — все предпочтения не заданы; файлы навигатора и конфигурацию Хоста ради значений не читай. Значение вне формата считай незаданным и скажи об этом.
- Не задано, а сценарию нужно — спроси для текущего разговора: timezone — в общем `clarify` с остальными блокирующими пробелами, стиль названий — по [Названия](#названия). Назови ключ, который Потребителю стоит задать, чтобы вопрос не повторялся. Ненужное сценарию не спрашивай.
- Просьба изменить предпочтение из чата («теперь я в Тбилиси») — не сохраняй. Назови ключ и новое значение для Потребителя (`eva.timezone = Asia/Tbilisi`) и по желанию пользователя применяй его только в текущем разговоре. Изменение у Потребителя действует в новом экземпляре агента Хоста.

## Названия

Не пытайся отличить владельца от участника публичного onboarding. Для нового названия используй явно заданное имя или `eva.habits.names`. Если привычка чувствительная, а имя и стиль не заданы, спроси о точном или нейтральном имени вместе с остальными блокирующими пробелами; выбор действует в текущем разговоре, ключ назови для Потребителя. Объясни, что названия видны в Habitify и его напоминаниях. Чувствительное название по собственной догадке не создавай; в сексуальной теме — [sexual-behavior.md](sexual-behavior.md#возраст).

## Открытый запрос

Отдельной настройки нет. «Давай настроим привычки», «с чего начать» — обычная работа без анкеты:

1. Проверь инструменты серверов `habitify_read` и `habitify` для сценария, включая Read-back, по [tools.md](tools.md#серверы-и-discovery). Покажи существующие привычки ([поиск](tools.md#поиск-привычки-по-названию)).
2. Если привычка и действие уже названы, найди её и выполни запрос без повторного выбора. Иначе предложи один подходящий ход одной строкой и выполни по «Да»; набор изменений — один Preview. Новую привычку веди по [experiments.md](experiments.md), выбранной — прочитай детали и заметку плана по [experiments.md](experiments.md#заметка-плана).

Потребность в группировке — [areas.md](areas.md#когда-предложить). Запрос Ритуала — [rituals.md](rituals.md); вопросы о Ритуалах и предпочтениях без запроса не задавай. Регулярные задания Ритма настраивает Потребитель: на просьбу о регулярном приглашении назови, какое задание нужно, и не создавай его. Разовый возврат к теме — Возврат по `skill_view(name="eva", file_path="references/initiative.md")`.

## Пометки Ритуалов

Пометки Ритуалов живут в `Eva/Пометки.md` Журнала Eva: `areaId` Областей, выбранных пользователем как Ритуалы, и для каждой — `habitId` первой привычки, если пользователь её назвал. Запись делается по ходу работы с Ритуалом ([rituals.md](rituals.md#ритуал-в-пометках)). `memory` Hermes Eva не использует.

Не храни в Пометках: предпочтения, даты и ритм обзоров, ID экспериментов и остальных привычек, состав и порядок Ритуала, План эксперимента, состояния «активный / Поддержание / пауза», Отметки, Тягу, вес, причины срыва, секреты.

### Запись Пометки

- Форма строки, чтение и запись — по `skill_view(name="eva", file_path="references/notebook.md")`. Журнал — служебная зона: Пометку по явному выбору пользователя пиши без отдельного согласия.
- Путь — `<корень>/Eva/Пометки.md`, корень — по «Корню Хранилища» в `notebook.md`: в разговоре абсолютный путь из переменных окружения, относительный `Eva/…` — только в фоне с `workdir`. Перед изменением перечитай файл: правки владельца важнее записей Eva. Меняй только строки Ритуалов и Safety-стопов этого скилла, чужие строки сохраняй. После записи проверь `read_file` — это Read-back Пометки; не совпало — `unverified`.
- Нет Хранилища или toolset `file` — назови недостающее; выбранный Ритуал действует только в текущем разговоре, сохранение не обещай.
- Файлы скиллов Eva (`SKILL.md`, `references/`, `tools.json`) только для чтения: не вызывай `skill_manage`, не создавай файлов настроек и не используй `memory`, даже если подсказка Hermes советует хранить что-то в скилле или памяти.

## Status

- `status` без объекта — значения `eva.timezone` и `eva.habits.names` из блока (незаданное — «не задано» с ключом для Потребителя), Ритуалы из `Eva/Пометки.md`, доступность инструментов `habitify_read` и `habitify` для основных сценариев по [tools.md](tools.md#серверы-и-discovery) и активные привычки.
- Эксперимент: найди привычку, прочитай детали и адресную статистику за запрошенный период (по умолчанию — текущая дата по [tools.md](tools.md#даты-и-единицы)). Покажи наблюдаемое поведение, доступные Отметки, дату обзора из доступного плана и ограничения данных. План нужен для разбора и даты обзора; простое чтение Отметок выбором заметки не задерживай.
- «Какие привычки сегодня?» или конкретный день — [Обзор дня](tools.md#обзор-дня), без записи Отметок.
- Ритуал — [rituals.md](rituals.md#статус).

Отделяй слова пользователя от прочитанного в Habitify. Соблюдение плана или факт обзора из пропущенных данных не выводи. Status только читает.

## Фоновый запуск

Задания Ритма создаёт и сопровождает Потребитель; этот скилл их не создаёт и не меняет, Возвраты ставятся только по `initiative.md` навигатора. Процедуру фонового запуска ведёт `eva`: он загружает этот скилл и следует [signals.md](signals.md). Запуск с маркером `[расписание eva]` или `[возврат eva]` читает Habitify и пишет только в Журнал Eva ([write-policy.md](write-policy.md#фоновый-запуск)); `clarify` в нём нет.

- Нужно чтение `habitify_read` в инструментах фонового запуска. Если его нет, назови недостающее и опирайся только на доступное, без обхода.
- Дата следующего обзора — только из Плана эксперимента; проведённые обзоры и ответы на предложения — в Журнале по `notebook.md`. Обзор, не отмеченный в Журнале, пропущенным не считай.
- Названия привычек в сообщении разрешены; форма и лимит — по `initiative.md`, Safety выше любой Инициативы ([signals.md](signals.md#общие-правила)).
