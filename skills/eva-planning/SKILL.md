# eva-planning

Раскладывай Фокус-лист по Свободным окнам одного дня, проверяй вместимость и ставь Брони под выбранные задачи. Что делать и что переносить, решает пользователь. Состояние каждый раз читай у провайдеров: задачи — SingularityApp, События, Брони и Распорядок — Google Calendar, Ритуалы — Habitify. Отвечай по-русски, identifiers сохраняй.

## Вход в сценарий

1. Своего провайдера и `tools.json` нет. Плану дня нужны `eva-calendar` и `eva-tasks`, Ритуалам — `eva-habits`: загрузи их голым именем, например `skill_view(name="eva-calendar")`, перед провайдером — их `references/write-policy.md`; инструменты — по их `tools.json` и `references/tools.md`.
2. Прочитай reference сценария из таблицы: `skill_view(name="<имя этого скилла>", file_path="references/<файл>.md")`; Markdown-ссылка файл не загружает.
3. Предпочтения — из блока `[Skill config …]` навигатора `eva` по [preferences.md](references/preferences.md).
4. Недоступный скилл или инструмент назови и порекомендуй подключить в Hermes; сам ничего не настраивай. Покажи доступную часть и недостающее.

## Записи

- Полную явную команду (Бронь, перенос задачи) выполняй сразу по правилам владельца, затем Read-back. Несколько явно названных записей — последовательно, без Preview.
- Набор, собранный агентом (Брони и смены `start` задач), покажи одним общим Preview на оба провайдера с порядком записей; после одного «Да» выполняй последовательно по правилам владельцев.
- Стоп на первой ошибке. Общий отчёт: `applied` (подтверждено Read-back), `unverified` (могло состояться, не подтверждено), `unapplied`. Неопределённый исход перечитай, запись не повторяй; автоматического отката нет. Предложенную Бронь не называй созданной до Read-back.
- Фоновый запуск Брони не создаёт и не переносит, только предлагает пересмотр ([signals.md](references/signals.md)).

## Уточнение и согласие

- Используй известное; необязательное и названное не спрашивай, относительную дату покажи в результате. Все блокирующие пробелы — один `clarify` без `choices`; полную явную команду не переспрашивай.
- Согласие на предложение агента или Preview — одна карточка `clarify` «Да»/«Нет» с полным текстом; без явного «Да» (timeout, пропуск, «Other») запись не выполняй.
- Размытое намерение уточняй редко через `grill-me` (`skills_list` → `skill_view`); если его нет, назови его и предложи установить в Hermes, своё интервью не веди.
- Запрос другого скилла или провайдера — одной строкой предложи ход и выполни после «Да». Перед записью в чужого провайдера загрузи его скилл и `references/write-policy.md`; без фактической загрузки передачу не объявляй.

## Границы

- Только один день; неделю не планируй.
- Daily open, выбор Фокус-листа, срок и состояние задач — `eva-tasks`.
- Вид календаря без задач, События и Распорядок — `eva-calendar`.
- Ритуалы и привычки — `eva-habits`; отдельные привычки Ритуала в календарь не попадают.
- Предпочтения только читай. Файлы скиллов Eva не меняй, `skill_manage` не вызывай.
