# Daily open и Daily close

## Общие правила

- Прочитай `eva.timezone` и `eva.tasks.workdays` по [settings.md](settings.md#предпочтения) и Режимы поддерева по [дереву](tree.md). Режим, которого нет ни у Проекта, ни у его Области, спроси по [settings.md](settings.md#когда-спрашивать-режим); по умолчанию не задавай.
- Правила включения режимов применяй к каждому кандидату, хвосту, остатку и затронутому Проекту по дню обзора; Срок их не отменяет.
- Фиксированного предела Фокус-листа нет. Календарь не читай и вместимость не обещай; скажи: «Календарь и доступное время не проверены».
- Даты, длительность и приоритет — по [tasks.md](tasks.md); результат, состояние и Следующий шаг — по [осмотру Проекта](projects.md#осмотр).
- Замеченное по ходу, но не входящее в обзор, обзор не прерывает: запиши Наблюдение и подними строкой в конце по [signals.md](signals.md#во-время-практики).
- В конце обзора отметь его в `Eva/Практики.md` по [signals.md](signals.md#отметки-в-практиках).

## Daily open

1. Определи сегодня в `eva.timezone`. Прочитай вчерашние хвосты через `task_list_overdue`, затем Today через `task_list_today`; оставь подходящие по режимам.
2. Ресурс дня возьми, если назван; иначе спроси: `низкий / обычный / высокий`. По самооценке предложи более короткий или широкий Фокус-лист; ресурс из числа Задач не вычисляй.
3. Если нужны другие кандидаты, прочитай открытые Задачи подходящих поддеревьев через `task_list` и Проекты через `project_get`. Всё дерево без необходимости не обходи.
4. С пользователем выбери стартуемые Задачи; при трудном старте — [tasks.md](tasks.md#трудный-старт).
5. Выбранным предложи `start` = сегодня. По каждому не выбранному хвосту и Задаче Today в допустимых режимах получи решение: оставить, снять Плановую дату, назначить дату пользователя или отменить после отказа (`task_update`, `task_move`, `task_cancel`). «Оставить» записи не требует.
6. Preview набора, собранного агентом: выбранные Задачи с `start` = сегодня, переформулировка каждой выбранной, которая не проходит проверку «как для обезьянки» по [tasks.md](tasks.md#формулировка), и решения по остальным. Выполни разрешённое и покажи Фокус-лист.
7. Предложи План дня `eva-planning` одной фразой «зачем» по [переходам](signals.md#переходы-после-практик): Фокус-лист выбран без календаря.

## Daily close

1. Назови день обзора. Прочитай остатки через `task_list_today`, `task_list_overdue`, при необходимости `task_list`; оставь подходящие по режимам. Today не исторический снимок: для другого дня недостающее спроси у пользователя.
2. По каждому остатку нужно решение: оставить, снять Плановую дату, перенести на дату пользователя, завершить выполненное или отменить после отказа (`task_update`, `task_complete`, `task_cancel`).
3. Затронутые Проекты возьми из диалога и доступных изменений Задач. Фильтр изменений `task_list` используй, только если он есть; при неполной истории спроси, какие Проекты затронуты.
4. Прочитай подходящие по режимам Проекты через `project_get`, дерево — по [tools.md](tools.md#дерево-в-разговоре); проведи [осмотр](projects.md#осмотр).
5. Проведи [Гвоздодёр](brain-dump.md#гвоздодёр); если он уже был сегодня отдельно, шаг пропусти.
6. Всплывшее разложи по [разбору по местам](brain-dump.md#разбор-по-местам): обязательство — во Inbox, мысль или идея — через `eva-notes`: мысль и личная идея — в заметку дня обзора, рабочая идея — в `Работа/` Хранилища. Записывай по явной просьбе сразу либо включи предложением в общий набор; автоматически не записывай.
7. Preview набора, собранного агентом, объединяет изменения остатков, Проектов и ещё не записанные Inbox items, строки заметки дня и рабочие идеи для `Работа/`. Уже выполненные явные команды не повторяй. Выполни разрешённое и сообщи результат.
