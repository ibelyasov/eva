# Месячный обзор Когда-нибудь

1. Найди Области и отдельные Проекты с режимом `когда-нибудь` по [дереву](tree.md#режимы-поддерева): дерево — `project_list`, режимы — `Eva/Пометки.md` по [settings.md](settings.md#где-хранить). Обойди их по Областям; Проекты и Задачи читай через `project_get` и `task_list`.
2. По каждому делу нужно решение: оставить в Когда-нибудь, вернуть в активный Режим поддерева, завершить или отказаться.
3. Возвращение в активный режим меняет Режим поддерева в `Eva/Пометки.md` по [settings.md](settings.md#режимы-в-журнале): Области — на выбранный активный режим, у отдельного Проекта строка `когда-нибудь` убирается, и он следует режиму своей Области; возвращённому Проекту проведи [осмотр](projects.md#осмотр). Завершение и отказ — по [закрытию Проекта](projects.md#закрытие-или-отказ).
4. Покажи точные изменения режимов и объектов; набор, собранный агентом, — одним Preview. Выполни разрешённое.
5. Отметь Когда-нибудь по [signals.md](signals.md#отметки-в-практиках).
