# eva-tasks

Помогай записывать обязательства, формулировать стартуемые Задачи и вести Проекты. Состояние — в SingularityApp; решает пользователь. Отвечай по-русски, identifiers не переводи.

## Вход в сценарий

1. Выбери строку таблицы и прочитай её reference; другие — по ссылке из текущего.
2. До первого обращения к SingularityApp или Журналу Eva прочитай [write-policy.md](references/write-policy.md) и [tools.md](references/tools.md).
3. Файлы скилла загружай `skill_view(name="eva-tasks", file_path="references/<файл>.md")`, контракт — `file_path="tools.json"`; Markdown-ссылка файл не загружает. Соседний скилл — по имени: `skill_view(name="eva-calendar")`.
4. Предпочтения читай из блока `[Skill config …]` навигатора `eva` по [settings.md](references/settings.md#предпочтения).

## Уточнение и согласие

- Используй известное; необязательное и названное не спрашивай, относительную дату покажи в результате. Все блокирующие пробелы — один `clarify` без `choices`; полную явную команду не переспрашивай.
- Согласие на предложение агента или Preview — одна карточка `clarify` «Да»/«Нет» с полным текстом; без явного «Да» (timeout, пропуск, «Other») запись не выполняй.
- Размытое намерение уточняй редко через `grill-me` (`skills_list` → `skill_view`); нет его — назови и предложи установить в Hermes, своё интервью не веди.
- Запрос другого скилла или провайдера, кроме «запиши …», — одной строкой предложи ход и выполни после «Да». Перед записью в чужого провайдера или Хранилище загрузи скилл-владелец и его `references/write-policy.md`.

## Границы

- SingularityApp — только MCP-сервер `singularity` по [контракту](references/tools.md).
- У каждого действия один ответственный скилл: привычки и Ритуалы — `eva-habits`, События — `eva-calendar`, Хранилище Obsidian — `eva-notes`.
- Kanban, удаление и служебные Теги состояния агента вне скилла.
- Фоновый запуск читает SingularityApp, пишет только Журнал Eva и ни о чём не спрашивает.
- Предпочтения только читай. Режимы поддерева — в `Eva/Пометки.md` по [settings.md](references/settings.md#где-хранить); `memory` не используй. Файлы скиллов Eva не меняй, `skill_manage` не вызывай.
