# Захват

Захват сохраняет присланное в разговоре без разбора. Поля — [fields.md](fields.md), проверка и Отчёт — [write-policy.md](write-policy.md#проверка-и-отчёт).

## Запиши

«Запиши …» обычными словами, без обязательных префиксов: место выбирает агент по смыслу и сообщает одной строкой, что и куда записал; владелец поправит словами.

| Что записать | Куда |
| --- | --- |
| Обязательство или действие | `eva-tasks`: Capture во Inbox SingularityApp; он не установлен — строка-задача `- [ ]` в заметке дня ([journal.md](journal.md#заметка-дня)) |
| Идея: возможность, «когда-нибудь подумать о…», без обязательства | Строка с `#идея` в заметке дня ([journal.md](journal.md#идеи)) |
| Мысль, наблюдение, запись о дне | Заметка дня ([journal.md](journal.md)) |
| Ссылка, пост, файл, «сохрани в базу», справка | Захват: источник в `Источники/…` или адресная заметка домена; Входящие хранилища — если адрес неясен или захват не удался |
| Неясно, задача это или мысль | `eva-tasks`: Inbox SingularityApp, Triage разберёт; он не установлен — строка-задача `- [ ]` в заметке дня |

- Передача `eva-tasks`: загрузи его по имени и прочитай из его каталога `references/write-policy.md`; запись ведёт он. Скилл не установлен — строка-задача в заметке дня, в строке Отчёта назови место. Установлен, но запись не удалась — назови это; в Хранилище задачу не дублируй.
- Несколько записей в одном сообщении — каждую по таблице, последовательно, стоп на первой ошибке.
- Приоритет выбора: явное указание места → подпись к вложению → смысл → тип файла. Префиксы `дневник:`, `входящие:`, `сохрани:` — договорённость, не команды хоста; если владелец их пишет, они задают место.

## Тип входа

| Вход | Что делать | Чего не делать |
| --- | --- | --- |
| Голая ссылка | [Ссылка](#ссылка): источник в домене поступления | Не считать прочитанной владельцем, не разбирать |
| Пересланный пост | Источник с `origin: source`, известная атрибуция в теле; ссылки поста — по просьбе | Не выдавать за слова владельца, автора не угадывать |
| Своя мысль, событие | Заметка дня; при явном адресе — туда | Не улучшать текст, не делать из состояния общий факт |
| Комментарий к привычке, проекту, курсу | Секция «Комментарии владельца» этой заметки; адресат неоднозначен — Входящие хранилища | Не дописывать мотивацию, не менять провайдера |
| PDF, документ, фото материала | [Файл](#файл) | Не заявлять OCR, чтение или понимание |
| Своё фото к записи дня | `Вложения/` и вставка `![[…]]` в строку заметки дня | — |
| Прямой вопрос | Ответ по [wiki.md](wiki.md#вопрос) | Не захватывать, не сохранять ответ без просьбы |
| Видео | Не захватывается; ссылку по просьбе — во Входящие хранилища | Не извлекать |
| Пейволл, вход по логину | Сохранить доступное с `capture: partial`; полный текст присылает владелец | Не обходить |

Домен поступления: общий — `Источники/…`; рабочий — `Работа/Источники/`; курс — `Обучение/<Курс>/Источники/`; сообщество — `Сообщества/<Сообщество>/Источники/`. Адрес неясен — общий.

## Ссылка

1. Извлеки текст страницы ([tools.md](tools.md#извлечение-страницы)). Нет инструмента извлечения — [без извлечения](#без-извлечения); ошибка или пустой ответ — [сбой](#сбой).
2. Найди источник с тем же `source_url` (поиск по `source_url:`). Есть — сначала [повтор](#повтор).
3. Путь — `<Источники домена>/Статьи/<Заголовок>.md` (у научной публикации — `Публикации/`, у расшифровки — `Транскрипты/`; в доменных `Источники/` без подпапок). Имя — по [правилу имён](fields.md#имена-файлов-и-папок). Проверь, что путь свободен; занят другим материалом — суффикс даты захвата по [без перезаписи](write-policy.md#без-перезаписи): `<Заголовок> (ГГГГ-ММ-ДД).md`.
4. Ответ усечён, а хост сохранил полный текст в файл и назвал путь — сразу запиши frontmatter, затем допиши тело из этого файла в оболочке: `cat "<файл>" >> "<заметка>"`. Хост пометил эту копию усечённой или полного текста нет — сохрани доступное с `capture: partial`. Ответ не усечён — запиши frontmatter и тело одной записью. Признаки усечения в Hermes — [tools.md](tools.md#hermes).
5. Посчитай `sha256` тела по [tools.md](tools.md#sha256) и впиши его точечной правкой вместо пустого значения `sha256: ""`.
6. `capture: full` — полный доступный текст страницы, картинки удалёнными ссылками. `capture: partial` — сохранён фрагмент (пейволл, усечённая копия, полный текст не сохранён, инструмент вернул пересказ, нет инструмента извлечения); причину напиши первой строкой тела. `processing: pending`; если владелец при захвате сказал, что разбор не нужен («для справки», «не разбирай»), — `skipped` ([fields.md](fields.md#по-типам)).
7. Проверка чтением (frontmatter и начало тела) и одна строка Отчёта: «Сохранено в <путь>: полный доступный Markdown, картинки — удалённые ссылки. Разбор не выполнялся.» При `skipped` вместо последней фразы — «Разбор не нужен».

Тело источника — только извлечённый текст, без выводов агента. Картинки не скачивай, полную копию с локальными картинками не делай.

## Без извлечения

Нет инструмента извлечения страницы — сохрани источник с `capture: partial` по шагам 2–7 [ссылки](#ссылка). Тело: первой строкой причина «Текст страницы не извлечён: нет инструмента извлечения страницы», затем ссылка и подпись владельца как есть. Имя — по подписи, иначе по домену ссылки. Строка Отчёта: «Сохранено в <путь>: только ссылка, текст страницы не извлечён (`capture: partial`). Разбор не выполнялся.» Текст страницы, присланный владельцем позже, сохраняется новой версией по [повтору](#повтор).

## Файл

1. Имя — по подписи или исходному имени файла, по-русски, по [правилу имён](fields.md#имена-файлов-и-папок). Проверь, что свободны и `<Имя>.<ext>`, и `<Имя>.md` (`test -e` в оболочке); занято — суффикс даты захвата по [без перезаписи](write-policy.md#без-перезаписи).
2. Скопируй вложение из пути, который назвал хост ([tools.md](tools.md#вложения)), в оболочке без перезаписи: `cp -n "<вложение>" "<Источники домена>/Файлы/<Имя>.<ext>"`, затем сверь `sha256sum` копии с исходным файлом; не совпало — стоп, «не сделано».
3. Рядом создай заметку `<Имя>.md`: `type: source`, `origin: source`, `sha256` байтов файла (`sha256sum "<файл>"`), `captured_at`, `ingested`, `capture: full`, `processing` по шагу 6 [ссылки](#ссылка); в теле — вставка `![[<Имя>.<ext>]]` и подпись владельца как есть.
4. Файл не распознавай, не извлекай текст и не пересказывай; чтение и OCR — только отдельной просьбой.
5. Проверка чтением заметки и наличия файла (поиском), одна строка Отчёта.

## Повтор

1. Если `sha256` нового тела известен до записи (файл полного текста или вложение) и равен сохранённому — новый файл не пиши, ответь: «Уже сохранено: <путь>».
2. Иначе сравни нормализованный текст нового извлечения с телом сохранённого: игнорируй различия пробелов и пустых строк вне блоков кода и одноразовые параметры у ссылок на картинки (подписи, размеры, cache-busters). Длинные тела сравни `diff` в оболочке и оцени, все ли отличия такого рода.
3. Совпало — новый файл не пиши. Отличается — новая версия рядом с датой захвата в имени, `processing` по шагу 6 [ссылки](#ссылка), старая не трогается; в теле новой — ссылка на прежнюю.

Редкие лишние версии допустимы: стабильный Markdown провайдер не гарантирует.

## Сбой

Если инструмент извлечения вернул ошибку или пустой текст, создай `Входящие/<Заголовок или домен> (ГГГГ-ММ-ДД).md` (имя — по [правилу имён](fields.md#имена-файлов-и-папок), путь свободен): `type: inbox`, `origin: source`, `received_at`, `channel` — канал поступления ([fields.md](fields.md#по-типам)), `source_url`, `capture: failed`, без `sha256` и `processing`; в теле — ссылка и подпись владельца как есть. Источник не создавай, другой способ извлечения не подставляй.

```text
Не удалось извлечь текст по <URL>. Ссылка сохранена во Входящих: <путь>.
Полная копия не получена; разбор не выполнялся.
```

## Входящие хранилища

`Входящие/` (и `Работа/Входящие/`) — место для материала с неясным адресатом или типом и для неудачного захвата. Заметка — `type: inbox` по [fields.md](fields.md). Разбор Входящих начинает владелец; автоматической обработки, сроков и ежедневных вопросов нет. Перенос из Входящих — по просьбе, с проверкой каждой записи. Служебная папка `Eva/` — Журнал Eva, а не Входящие хранилища: из неё ничего не переносится и не разбирается ([write-policy.md](write-policy.md#журнал-eva)).

## Передача от `eva-tasks`

`eva-tasks` передаёт записи для Хранилища в двух сценариях. Пишет `eva-notes` по этому файлу и [journal.md](journal.md), проверяет каждую запись чтением и возвращает путь и результат проверки. SingularityApp `eva-notes` не трогает.

### Triage

`eva-tasks` передаёт текст Inbox item, его ID и дату создания в поясе дня ([journal.md](journal.md#заметка-дня)). Даты нет — блокирующий пробел для Идеи.

- Идея — строка с `#идея` в заметке дня за дату создания Inbox item ([journal.md](journal.md#идеи)).
- Справка — захватом: ссылка или файл — источник в `Источники/…`, текст — адресная заметка домена, если адресат однозначен; иначе Входящие хранилища (`channel: singularity`).
- Inbox item отменяет `eva-tasks` и только после подтверждённой записи.

### Выгрузка из головы

Владелец перечисляет всё, что держит в голове; `eva-tasks` раскладывает записи по местам и показывает один общий Preview всех операций — Inbox SingularityApp и Хранилища — по своим правилам записи. У каждой строки Хранилища в Preview — её текст и место: заметка дня, источник или Входящие хранилища. «Да» на общий Preview разрешает и эти строки ([write-policy.md](write-policy.md#разрешение)); без «Да» в Хранилище ничего не пишется.

- Идея — строка с `#идея` в заметке дня ([journal.md](journal.md#идеи)).
- Мысль, наблюдение, запись о дне — строка в заметке дня ([journal.md](journal.md#заметка-дня)).
- Справка: ссылка, пост, файл, материал — захватом по этому файлу; адрес неясен — Входящие хранилища (`channel` — канал, по которому пришла Выгрузка).
- День — дата события, если владелец её назвал, иначе день Выгрузки в поясе дня. Слова владельца — как есть, без улучшения, сводки и выводов.
- Записи — последовательно в порядке Preview, стоп на первой ошибке; результат каждой — путь и проверка чтением для общего отчёта `eva-tasks`.
