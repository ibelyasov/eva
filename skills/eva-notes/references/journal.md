# Дневник и идеи

## Заметка дня

- Путь — `Дневник/ГГГГ/ГГГГ-ММ-ДД.md`. Заметка создаётся при первой записи за день и содержит только секцию владельца.
- День — по событию, а не по моменту получения: сутки от полуночи в поясе дня. «Вчера», «в субботу» вычисляй от текущей даты в этом поясе, не переспрашивай. Дата события неизвестна — день получения, исходная формулировка сохраняется.
- Пояс дня — `eva.timezone` из блока Предпочтений навигатора `eva`. Блок есть, а ключ не задан — спроси пояс одним вопросом для этого разговора и назови ключ для Потребителя. Блока нет — местный пояс машины агента: текущие дата, время и смещение — `date '+%F %T %z'` в оболочке.
- Каждая запись — одна строка в секции «Записи владельца»: время события, если известно, текст владельца как есть и момент получения.
- Обязательство или действие при неустановленном `eva-tasks` — строка-задача Obsidian в той же секции: `- [ ] Текст владельца. (получено: "…")`. Срок, если владелец его назвал, — словами владельца в тексте строки.

```markdown
---
type: journal
origin: owner
date: 2026-10-10
summary: Записи за 10.10.2026
---

# 2026-10-10

## Записи владельца
- 09:30 — Текст владельца. (получено: "2026-10-11T18:42:00+03:00")
- вечером — Текст владельца. (получено: "2026-10-11T18:45:00+03:00")
- Подумать о мастерской на даче. #идея (получено: "2026-10-11T19:02:00+03:00")
```

- Время события известно только приблизительно («вечером») — так и запиши; `00:00` не подставляй. Неизвестно — без времени.
- Новую строку дописывай в конец секции точечной правкой по свежему тексту заметки.
- Без итогов дня, выводов, диагнозов и пересказа агентом. SingularityApp, Google Calendar и Habitify остаются владельцами своих данных: в дневник — только значимое словами владельца и ссылки.
- Личные состояния не становятся фактами вики; в вики переходят только устойчивые знания с происхождением и через План сущностей.
- Дневник — заметки `Дневник/`; служебная папка `Eva/` (Журнал Eva) — не дневник. Записи владельца о дне идут только в заметку дня, служебные записи Eva — только в `Eva/`.

## Неделя

`Дневник/ГГГГ/ГГГГ-Www.md` создаётся только по просьбе владельца записать что-то о неделе; структура та же, `type: journal`, `date` — понедельник недели. Год и номер — ISO-недели: 01.01.2027 → `Дневник/2026/2026-W53.md`. Итоги дня и недели агент сам не пишет.

## Идеи

Идея — возможность без обязательства: «когда-нибудь подумать о…», «а что если…». Обязательство или действие — задача ([capture.md](capture.md#запиши)).

### Запись идеи

- Одна идея — одна строка с `#идея` в секции «Записи владельца» заметки дня. Идея из Inbox SingularityApp — в заметку дня за дату создания Inbox item.
- Тег `#идея` пиши ровно так; похожие маркеры (`#идея2`) и примеры с `#идея` в коде в дневнике не используй: страница идей ищет строки.
- Статусов, рейтингов и обязательного обзора у идей нет.

### Страница всех идей

При первой идее, если `Идеи/Идеи.md` нет, создай её в той же записи и назови в Отчёте:

````markdown
# Идеи

Строки с #идея из Дневника:

```query
path:"Дневник/" line:(#идея)
```

## Развиваемые идеи
````

Embedded Search показывает совпадения по файлам дней; отдельные строки идей он не извлекает в таблицу. Работу блока на Android проверяет владелец. Блок запроса без просьбы не меняй.

### Покажи идеи

«Покажи идеи за месяц» — найди строки `#идея` поиском в `Дневник/`, покажи их с датами и назови прочитанный диапазон. Отсутствие совпадений не доказывает, что идей не было.

### Развитие идеи

- Отдельная заметка — только когда владелец решил развивать идею: `Идеи/<Название>.md`, `type: idea`, `origin` по основному тексту. В теле — ссылка на исходный день (`[[Дневник/2026/2026-10-11]]`), слова владельца в «Записях владельца», материалы и связи.
- Добавь строку `- [[Идеи/<Название>]]` в раздел «Развиваемые идеи» страницы `Идеи/Идеи.md`.
- Исходная строка дня не меняется. ID блока добавляй, только если нужна устойчивая ссылка на строку.
- Решение действовать — по просьбе владельца передай задачу или проект `eva-tasks`; он не установлен — строка-задача в заметке дня ([заметка дня](#заметка-дня)).
