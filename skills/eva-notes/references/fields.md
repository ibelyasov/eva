# Поля заметок

Поля frontmatter — английские, значения — по-русски там, где это текст. Неизвестное не выдумывай: необязательное поле опускай, неизвестный ID провайдера — `""` с отметкой в Отчёте.

## Форматы

- Календарная дата — `ГГГГ-ММ-ДД` без кавычек: `created`, `updated`, `ingested`, `date`.
- Момент — RFC 3339 с поясом в кавычках: `captured_at: "2026-10-11T18:42:00+03:00"`. Пояс — `eva.timezone`.
- Ссылка на заметку — wikilink в кавычках: `course: "[[Обучение/Python/Python]]"`.
- ID провайдера — строка в кавычках, не число.
- `aliases` — только настоящие варианты названия (RU/EN, сокращения), не синонимы из головы. `tags` — по потребности и только из таксономии `SCHEMA.md`.

## Имена файлов и папок

Правило действует для имени файла и для каждого сегмента пути, который агент строит из названия: сфера, курс, секция, лекция, сообщество, проект, а также заметка `<Курс>.md` или `<Сообщество>.md`, совпадающая с папкой. Имя строится из заголовка, подписи или исходного имени так, чтобы файл и папка создавались на Mac и Android и не ломали wikilinks; тот же очищенный сегмент повторяется в wikilinks вроде `course: "[[Обучение/<Курс>/<Курс>]]"`:

- Символы `: ? * " < > | # ^ [ ] \ /` и управляющие замени: `:` — на ` -`, остальные — на пробел; повторные пробелы схлопни, точки и пробелы в начале и конце убери.
- Обрежь по границе слова до ≈ 100 символов; имя вместе с суффиксом даты и расширением — не больше 255 байт UTF-8.
- Исходный заголовок сохрани в `title` и H1: тогда они отличаются от имени файла. Исходное название папки — в H1 и `title` её заметки.
- Пустое после замены имя — домен ссылки или «Файл» с датой захвата.

## Общие поля

У каждой контентной заметки: `type`, `origin` (`owner | source | agent`), `summary` — одна короткая фраза для `index.md` и выборок. `aliases` — при настоящих вариантах, `tags` — по потребности. Служебные `SCHEMA.md`, `AGENTS.md`, `index.md`, `log.md` и `Идеи/Идеи.md` общих полей не требуют.

## По типам

| `type` | Где | Обязательные сверх общих | По возможности |
| --- | --- | --- | --- |
| `entity`, `concept`, `comparison`, `query`, `summary` | `Вики/…`, `Работа/Вики/` | `title`, `created`, `updated`, `tags` (допустим `[]`), `sources`; обычно `origin: agent` | `confidence`, `contested`, `contradictions` по условиям ниже |
| `source` | `Источники/…` и доменные `Источники/` | `origin: source`, `ingested`, `sha256`, `captured_at`, `capture: full \| partial` | `source_url`, `author`; `title`, если имя файла отличается от заголовка |
| `habit` | `Жизнь/Мои привычки/` | `habitify_id` | `provider_url` |
| `project` | `Проекты/`, `Работа/Проекты/` | `singularity_id` | `provider_url` |
| `course` | `Обучение/<Курс>/`, `Сообщества/<Сообщество>/Курсы/` | — | `url`; `community` у курса сообщества; `sources` при синтезе |
| `lecture` | Папки секций курса | `course` | `sources` у конспекта |
| `community` | `Сообщества/<Сообщество>/` | — | `url`; `sources` при синтезе |
| `journal` | `Дневник/ГГГГ/` | `origin: owner`, `date` | — |
| `inbox` | `Входящие/`, `Работа/Входящие/` | `received_at`, `channel` | `source_url`, `capture: failed` |
| `idea` | `Идеи/<Название>.md` | — | — |

- Пять wiki-типов — контракт `llm-wiki`, их lint проверяет основа. Остальные `type` — расширение схемы; lint вики их по требованиям wiki не проверяет.
- `title` совпадает с H1 и с именем файла, кроме изменений по [правилу имён](#имена-файлов-и-папок). `updated` меняется при содержательной правке, не при синхронизации.
- `sources` — список wikilinks на реально использованные источники; точное место — в теле.
- `confidence: high | medium | low` — по правилам основы, для одного источника, мнений и быстро меняющихся тем; без процентов.
- `contested: true` — есть неразрешённое противоречие; обе позиции с источниками и датами — в теле. `contradictions` — список wikilinks на конфликтующие страницы, если они есть.
- `source`: `sha256` — тела после frontmatter, у файла — байтов файла; `captured_at` — момент захвата снимка; `ingested` — его дата; `capture` — полнота захвата, не прочтение. Захват со сбоем — `inbox` с `capture: failed`, не `source`.
- `habit`, `project`: ID только читается через скилл-владелец; `provider_url` — только если ссылку вернул провайдер, из ID её не собирай. Отметки, планы, статусы, задачи и сроки в заметку не попадают.
- `journal`: время события и получения — в строке записи ([journal.md](journal.md)), не во frontmatter; `summary` — нейтрально «Записи за ДД.ММ.ГГГГ».
- `inbox`: `channel` — канал поступления (`telegram`, `singularity`, `file`). `origin` — `owner` для своего текста, `source` для внешнего материала, в том числе неудачной ссылки.
- `idea`: `origin` — `owner` или `agent` по основному тексту; ссылка на исходную строку дня — в теле.
- Статусы, рейтинги, прогресс, сроки обзора, `categories` и `related` не вводи.

## Примеры

```yaml
---
title: Омега-3
created: 2026-10-11
updated: 2026-10-11
type: concept
origin: agent
summary: Полиненасыщенные жирные кислоты — источники, дозировки, исследования
aliases: [Omega-3, ПНЖК омега-3]
tags: []
sources: ["[[Источники/Статьи/Омега-3 и воспаление]]"]
confidence: medium
---
```

```yaml
---
type: source
origin: source
summary: Статья о связи омега-3 и воспаления
source_url: https://example.org/omega-3
author: [Имя Автора]
captured_at: "2026-10-11T18:42:00+03:00"
ingested: 2026-10-11
sha256: ""
capture: full
---
```

`sha256: ""` — только на время записи: значение вписывается сразу после подсчёта по [capture.md](capture.md#ссылка).

## Маркеры утверждений

В агентских заметках у каждого существенного утверждения — маркер и основание в теле, рядом с утверждением:

```markdown
- [extracted] Пересказ утверждения автора — [[Источники/Статьи/Материал]], §2.
- [inferred] Вывод агента — из [[Источник А]] и [[Источник Б]]; ход вывода и границы.
- [ambiguous] Неоднозначное место — [[Источник А]], §3; возможные прочтения.
```

`[extracted]` — взято из указанного материала, не доказанная истина. `[inferred]` — вывод агента, не слова владельца. `[ambiguous]` — источник допускает разные прочтения. Страницу, раздел или таймкод указывай только проверенные. Маркеры не переносятся во frontmatter.
