# Предпочтения и status

Своих предпочтений у Плана дня нет: он использует домашний пояс и предпочтения календаря. Их задаёт Потребитель при подключении. Хост всегда загружает навигатор `jedikit` и добавляет после его текста блок значений:

```text
[Skill config (from ~/.hermes/config.yaml):
  jedikit.timezone = Europe/Moscow
  jedikit.calendar.day_bounds = 08:30-22:30
  jedikit.calendar.gap_minutes = (not set)
]
```

- Значения напечатаны как Python `str()`: список — `['a', 'b']`, строка — без кавычек.
- `(not set)` или отсутствие ключа — значение не задано. Блока в контексте нет — не задано ни одно предпочтение: назови это.
- Значение не по формату не угадывай: назови ключ и ошибку для Потребителя и считай значение незаданным.

Предпочтения только читай. Записей в `memory` у скилла нет; значения не сохраняй ни в `memory`, ни в файлы, `skill_manage` не вызывай.

## Ключи

| Ключ | Для чего | Не задан |
| --- | --- | --- |
| `jedikit.timezone` | Домашний пояс IANA: сегодня, текущее время, относительные даты | Нужна дата — спроси пояс |
| `jedikit.calendar.read_calendars` | Календари чтения, список `<account>:<calendarId>` | Все видимые календари по `list-calendars` |
| `jedikit.calendar.write_calendar` | ID календаря записи Броней | `primary` |
| `jedikit.calendar.write_account` | Nickname аккаунта календаря записи | Подключён один аккаунт — он; несколько — спроси, когда нужна Бронь |
| `jedikit.calendar.day_bounds` | Границы дня `HH:MM-HH:MM` для Свободных окон и Броней; может пересекать полночь | Спроси, когда нужны окна или Бронь |
| `jedikit.calendar.gap_minutes` | Целое число минут зазора между Бронью и Событием или Распорядком | 0 — покажи это в результате |
| `jedikit.calendar.reminders.bookings` | Напоминания Броней: `calendar`, `none` или набор `popup 30, email 1440`; перевод в аргументы — раздел «Напоминания» в `references/tools.md` скилла `jedikit-calendar` | `calendar` |

## Не задано

Действует значение из столбца «Не задан». Если default нет и значение блокирует сценарий, спроси его в том же `clarify`, что и прочие блокирующие пробелы: ответ действует только в текущем разговоре. В ответе назови ключ, который нужно задать у Потребителя. Ненужное сценарию не спрашивай. В фоновом запуске `clarify` нет: назови незаданный ключ и покажи доступное.

## Просьба изменить предпочтение

«Зазор 15 минут», «мой день с 8 до 22», «для Броней без напоминаний» — не сохраняй. Назови ключ и новое значение для Потребителя, например `jedikit.calendar.gap_minutes = 15`; если пользователь хочет, применяй его до конца текущего разговора. Значение у Потребителя начинает действовать в новом экземпляре агента Хоста. Смена предпочтения уже созданные Брони не меняет.

## Status

Без чтения аккаунтов и без записей: покажи `jedikit.timezone` и ключи таблицы из блока, незаданные — с действующим значением или пометкой «спросит, когда понадобится»; доступность `jedikit-calendar`, `jedikit-tasks`, `jedikit-habits` и их инструментов по видимому списку или `tool_search`/`tool_describe`.
