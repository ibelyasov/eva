# Словарь JediKit

Определения объясняют слова человеческим языком. Правила операций с этими объектами — у скилла-владельца.

## Что куда относится

| Что у пользователя | Как называется | Чей скилл |
| --- | --- | --- |
| Договорённость с людьми на время: встреча, приём, занятие с тренером | Событие | `jedikit-calendar` |
| Дело без договорённости, обязательство «не забыть», запись с неясным местом | Задача или Inbox item | `jedikit-tasks` |
| Многошаговое дело с результатом | Проект | `jedikit-tasks` |
| Идея: возможность без обязательства | Строка с `#идея` в заметке дня | `jedikit-notes` |
| Мысль, наблюдение, запись о дне | Заметка дня | `jedikit-notes` |
| Ссылка, файл, справочный материал | Источник в `Источники/…` или адресная Заметка; неясное и неудачный захват — Входящие хранилища | `jedikit-notes` |
| Знания о привычке и «зачем мне», материалы и решения проекта | Заметка о привычке или о проекте | `jedikit-notes` |
| Поведение, которое хочется проверить или закрепить | Эксперимент на привычке | `jedikit-habits` |
| Несколько привычек подряд в определённое время дня | Ритуал | `jedikit-habits` |
| Регулярный блок с устойчивым временем на ленте дня: Ритуал целиком, сон | Распорядок, только по просьбе | `jedikit-calendar` |
| Время сегодня под конкретную задачу | Бронь | `jedikit-planning` |

В календарь попадает то, что занимает определённый промежуток в определённый момент и должно быть видно на ленте дня: Событие, Бронь, Распорядок. Отдельные привычки внутри Ритуала и привычки без устойчивого времени туда не попадают. «Плавание с тренером во вторник в 19:00» — Событие по договорённости; сама привычка плавать остаётся в Habitify.

В Хранилище — знания, значимое о дне и ссылки на объекты провайдеров. Задачи, Отметки и События остаются у провайдеров; План эксперимента — в заметке привычки Habitify, а не в Хранилище. «Запиши …» обычными словами агент направляет по этой таблице сам и одной строкой сообщает, что и куда записал.

## Календарь и План дня

| Термин | Объяснение |
| --- | --- |
| Событие | Обязательство в календаре со временем: встреча, приём, договорённость. Намерение без договорённости — задача. |
| Бронь | Время в календаре под задачу. Это ссылка, а не копия: срок, состояние и выполнение остаются в SingularityApp. Прошедшая Бронь ничего не закрывает. |
| Распорядок | Роль события в календаре: регулярный блок поведения с устойчивым временем и длительностью. Ставится только по просьбе. Не путать с Режимом поддерева. |
| План дня | Фокус-лист, разложенный по окнам календаря, с проверкой вместимости и Бронями. Только на один день. |
| Свободное окно | Промежуток без Событий, Броней и Распорядка внутри границ дня из предпочтений. |
| Категория цвета | Смысл занятия записи в календаре, задающий её цвет: Встречи, Общение, Работа и фокус, Обучение, Заряд, Досуг, Покой, База или Рутина. Не роль записи; «Рутина» — не Распорядок. |

## Задачи — SingularityApp

| Термин | Объяснение |
| --- | --- |
| Область | Проект верхнего уровня, задающий контекст жизни: Работа, Личное или выбранный пользователем. |
| Папка | Проект с дочерними проектами. Может содержать одиночные задачи; своего результата и Следующего шага не требует. |
| Проект | Проект без дочерних проектов: многошаговое дело с результатом и стартуемым Следующим шагом. |
| Режим поддерева | Наследуемый признак Области или Папки: рабочие дни, личные дни, всегда или когда-нибудь. |
| Когда-нибудь | Режим поддерева: проекты не попадают в Daily open, не требуют Следующего шага и пересматриваются ежемесячно. |
| Задача | Одно физическое действие: глагол, объект и видимый признак готовности. |
| Следующий шаг | Задача проекта, которую можно начать сейчас; обычно одна, две — если независимы и параллельны. |
| Раздел | Блок задач внутри проекта, когда у длинного проекта видны реальные части. |
| Тег | Пользовательский признак для повторяющегося выбора между задачами разных проектов. |
| Чек-лист | Список-памятка внутри одной задачи, а не план шагов. |
| Inbox item | Сырая, ещё не разобранная запись во входящих. |
| Capture | Немедленная запись обязательства или записи с неясным местом во Inbox без классификации. Идея, мысль, ссылка из «запиши …» уходят в Хранилище. |
| Triage | Разбор одного Inbox item: тип, чистовая формулировка, место в дереве. |
| Идея / Справка / Встреча | Inbox item, который не задача и не проект. Идея — возможность без обязательства: живёт строкой с `#идея` в заметке дня. Справка — материал для знания. Идею и Справку из Inbox переносит в Хранилище `jedikit-notes`; Встреча с договорённостью и временем становится Событием. Inbox item отменяется после подтверждённой записи на новом месте. |
| Срок | Внешний жёсткий срок (`deadline`), после которого наступают последствия. |
| Плановая дата | Дата, которую пользователь выбрал, чтобы начать задачу (`start`); не Срок. |

## Обзоры

| Термин | Объяснение |
| --- | --- |
| Daily open | Утренний обзор: вчерашние хвосты, Ресурс дня, Фокус-лист. Следом — План дня. |
| Ресурс дня | Самооценка «низкий / обычный / высокий» для размера Фокус-листа, а не измерение. |
| Фокус-лист | Выбранные на сегодня задачи, без проверки календаря и вместимости; её делает План дня. |
| Daily close | Вечерний обзор: остатки дня, затронутые проекты, Гвоздодёр. Не дневник: заметку дня ведёт `jedikit-notes`. |
| Гвоздодёр | Обратная прокрутка прошедшего дня, чтобы вытащить незаписанные обязательства. |
| Weekly | Еженедельный обзор Inbox, всех проектов, Следующих шагов и структуры. |
| Inbox debt | Накопившиеся неразобранные Inbox items, разбираемые отдельными сессиями по 15, 10 или 5 минут. |

## Привычки — Habitify

| Термин | Объяснение |
| --- | --- |
| Область Habitify | Группа привычек; не то же, что Область в SingularityApp. Может быть отмечена как Ритуал. |
| Ритуал | Группа привычек, выполняемых подряд в определённое время дня; в Habitify — Область, отмеченная как Ритуал. Время старта — напоминание первой привычки; порядок задаётся ручной сортировкой в приложении; длительности в Habitify нет. Сон — одно действие, а не Ритуал. |
| Эксперимент | Проверка одной гипотезы об одном наблюдаемом поведении, привязанная к привычке. |
| План эксперимента | Текст в заметке привычки Habitify: цель, поведение, триггер, минимальное действие или замена, if–then, дата обзора, Stop-rule. |
| Отметка | Запись о выполнении, срыве, пропуске или количестве за дату. |
| Тяга | Момент сильного желания сорваться; скилл предлагает 1–3 действия из плана. Не диагноз. |
| Обзор эксперимента | Разбор по плану: оставить, изменить одну вещь, пауза или завершить. |
| Поддержание | Эксперимент, ставший привычным; обзор раз в месяц. |
| Stop-rule | Заранее оговорённое условие остановки эксперимента. |
| Safety-стоп | Остановка коучинга при признаках клинического риска с направлением к специалисту. |

## Хранилище — Obsidian

| Термин | Объяснение |
| --- | --- |
| Хранилище | Хранилище Obsidian владельца — личная база знаний: вики, источники, дневник, идеи, Сферы жизни, работа, обучение, сообщества, проекты. Ведёт `jedikit-notes`: агент пишет, владелец читает, комментирует и утверждает План сущностей. |
| Заметка | Markdown-файл Хранилища. Слова владельца в Заметке агент не переписывает. |
| Заметка дня | Заметка Дневника за одну дату события: записи о дне и Идеи строками с `#идея`. Создаётся при первой записи за день. Не Daily close и не список остатков задач. |
| Заметка о привычке / о проекте | Знания, контекст и ID объекта провайдера. План эксперимента, Отметки, статус и задачи остаются в Habitify и SingularityApp. Заметка о привычке — не заметка привычки Habitify. |
| Обратная ссылка | Строка `Obsidian: <путь>` и, если задано имя Хранилища, ссылка `obsidian://` в описании привычки Habitify или заметке проекта SingularityApp. Ставится при создании Заметки о привычке или проекте. |
| Входящие хранилища | Папка `Входящие/` Хранилища: материал с неясным местом и ссылка, которую не удалось извлечь. Разбирает владелец. Не Inbox SingularityApp. |
| Сфера жизни | Личный раздел Хранилища в группе `Жизнь/`: мои привычки, питание, здоровье и другие. Не Область SingularityApp и не Область Habitify. |
| План сущностей | Одно сообщение перед разбором материала: какие Заметки вики создать, дополнить или только сослаться. Владелец отвечает свободным текстом; без ответа ничего не пишется. Не Preview. |
| Hold | «Держи X» — агент не меняет Заметку X до «отпусти X». |
| Отчёт | Сообщение после записи в Хранилище: сделано, не проверено, не сделано. |

## Записи и Hermes

Эти слова встречаются в отчётах скиллов.

| Термин | Объяснение |
| --- | --- |
| Preview | Точный список изменений, собранных агентом, до одного подтверждения. Одиночное предложение агента — одна строка; согласие — «Да» в карточке `clarify`. |
| Группа операций | Две и более записи подряд со стопом на первой ошибке. Названные пользователем — сразу; собранные агентом — после одного Preview. |
| Read-back | Чтение записанного обратно у провайдера после каждой записи; ответ на запись его не заменяет. В Хранилище — чтение файла после записи. |
| applied / unverified / unapplied | Подтверждено Read-back / могло состояться, но не подтверждено / не выполнено. |
| Инструменты хоста | Операции провайдера, которые Hermes даёт агенту через MCP-серверы `singularity`, `habitify_read`, `habitify`, `google_calendar`, и встроенные инструменты Hermes для файлов Хранилища; подключение и авторизация принадлежат Hermes. |
| Контракт инструментов | Декларативный `tools.json` провайдерного скилла: какие операции он ожидает от Hermes. Не настройка подключения. |
| Адаптер хоста | Доверенный компонент Hermes с операциями Habitify; ключ остаётся у адаптера. |
| Native memory | Встроенная память Hermes, инструмент `memory`; JediKit хранит в ней только пометки объектов, а не предпочтения, задачи, Отметки или проведённые обзоры. |
| Предпочтение | Значение, которое Потребитель задаёт один раз в `skills.config` Hermes: часовой пояс, рабочие дни, календари, границы дня, зазор, напоминания, имя Хранилища для ссылок `obsidian://`. Скиллы читают его из блока `[Skill config …]` после `jedikit` и не меняют. |
| Пометка объекта | Режим поддерева Области или Папки SingularityApp, Ритуал Habitify. Скилл-владелец спрашивает её, когда сценарию не хватает, и сохраняет в `memory`. |
| Приглашение | Сообщение по расписанию Hermes, которое зовёт к обзору; задание заводит Потребитель, фоновый запуск только читает. |
| Потребитель | Тот, кто подключает JediKit к Hermes владельца и задаёт предпочтения и расписания. |
