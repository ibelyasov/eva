# Карта команд Eva

Команда и естественная фраза равноправны. `status` и `help` есть у нескольких скиллов: называй их вместе с именем скилла. Отдельного setup в чате нет: предпочтения задаёт Потребитель, пометки объектов скилл-владелец спрашивает по ходу работы и сохраняет в `Eva/Пометки.md`. Карта объясняет возможности; выполнение, инструменты и правила операций определяет загруженный скилл-владелец.

## `eva-tasks` — задачи и проекты, SingularityApp

| Команда или запрос | Результат |
| --- | --- |
| «Добавь задачу …», материал с этой просьбой | Задача с чистовой формулировкой и заметкой на месте по смыслу, при сомнении — во Inbox; затем строка с формулировкой и местом |
| `capture`, «запиши», «сохрани, чтобы не забыть» | Обязательство или неясное — Inbox item с исходным текстом; идея, мысль, ссылка, файл — в Хранилище через `eva-notes`; затем строка, что и куда записано |
| `triage`, «разберём Inbox», «уточни задачу», смена даты | Тип Inbox item, чистовая формулировка, место в дереве; Срок или Плановая дата |
| `project`, «добавь проект», «проверь проект», «следующий шаг», «закрой проект» | Проект с эмодзи в Области, стартуемый Следующий шаг, судьба открытых задач |
| Заметка о проекте в Хранилище | ID проекта для `eva-notes` и обратная ссылка в заметке проекта SingularityApp |
| Разделы и «подпроекты», Теги, Чек-лист, явное изменение состояния задачи | Пользовательская структура или названное действие с задачей |
| `daily open`, «начнём день» | Вчерашние хвосты, Ресурс дня, Фокус-лист |
| `daily close`, «закроем день» | Остатки дня, затронутые проекты, Гвоздодёр: обязательства — во Inbox, мысли и личные идеи — в заметку дня, рабочие идеи — в `Работа/` Хранилища через `eva-notes` |
| «Гвоздодёр», «вспомним день», «прокрутим день назад» | Гвоздодёр отдельно от Daily close: обратная прокрутка дня, незаписанные обязательства — во Inbox |
| «Выгрузка из головы», «выгрузим всё из головы», «в голове куча дел» | Выгрузка из головы: владелец перечисляет всё без сортировки, затем каждая запись — по месту: обязательство во Inbox, мысль и личная идея в заметку дня, рабочая идея в `Работа/` Хранилища — через `eva-notes` |
| `weekly`, «еженедельный обзор» | Inbox, все проекты, Следующие шаги, структура |
| «Пересмотрим когда-нибудь» | Ежемесячный пересмотр поддеревьев Когда-нибудь |
| «Накопился Inbox» | Отдельная сессия Inbox debt |
| Ответ на утреннее сообщение, «начнём день» после него | Daily open; после него — предложение План дня `eva-planning` |
| `status` | Предпочтения, Режимы поддерева из `Eva/Пометки.md` и доступность инструментов, без чтения содержимого задач |
| `help` | Справка по задачам без обращения к аккаунту |

Встречу из Inbox с датой и временем создаёт как Событие `eva-calendar`; исходным Inbox item управляет `eva-tasks`. Идею из Inbox `eva-notes` переносит по своим правилам: личную — строкой с `#идея` в заметку дня, рабочую — в `Работа/` Хранилища; Справку — захватом: источник в `Источники/…` или адресная Заметка, Входящие хранилища — если адрес неясен. Исходный Inbox item отменяется только после подтверждённой записи: «перенеси и отмени» — сразу, «перенеси» — с предложением отменить. Kanban не поддерживается.

## `eva-habits` — поведение и Ритуалы, Habitify

| Команда или запрос | Результат |
| --- | --- |
| `design` | Одна гипотеза об одном поведении и План эксперимента |
| `log` | Отметка за дату или явно выбранная отмена |
| `urge` | Поддержка при Тяге по Плану эксперимента |
| `review` | Обзор эксперимента: оставить, изменить одну вещь, пауза или завершить |
| `adjust` | Изменение одной вещи в Плане эксперимента |
| `pause`, `archive` | Пауза или архив выбранной привычки |
| Явное удаление привычки, области или заметки | Запрошенное удаление по правилам владельца |
| `areas` | Группировка привычек по Областям Habitify |
| `rituals`, «собери ритуал» | Существующие привычки в Области Habitify, отмеченной как Ритуал |
| «Добавь звено», «убери звено» | Привычка входит в Ритуал или снимается с его Области без удаления; новое поведение начинается как эксперимент |
| «Сдвинь утренний ритуал на 7:00» | Новое время старта — напоминание первой привычки; связанный блок Распорядка меняет `eva-calendar` |
| «Статус ритуала» | Сколько привычек отмечено и какие пропущены; «выполнен» — только когда отмечены все |
| «Ритуал выполнен», «сделал утренний ритуал» | Отметки всех привычек Ритуала за дату |
| «Обзор ритуала» | Разбор Ритуала целиком |
| Заметка о привычке в Хранилище | ID привычки для `eva-notes` и обратная ссылка в описании привычки Habitify; План эксперимента, даты и Отметки остаются в Habitify |
| `status` | Предпочтения, Ритуалы и доступность инструментов |
| Еда, вес | Гипотеза о пищевом поведении без диеты |
| Порно, мастурбация | Отдельные эксперименты по каждому поведению |
| Сокращение, отказ, вещества | Учитываемое событие, критерии и безопасный вариант |
| Доказательства, сроки формирования, серия | Границы уверенности |
| `help` | Справка по привычкам без обращения к аккаунту |
| Time Off | Инструкция для приложения; команды `off` нет |

Порядок привычек Ритуала задаётся ручной сортировкой в приложении. Напоминания «после отметки A напомнить B» (`habitStacks`) — только по просьбе. Сон — одно действие, а не Ритуал.

## `eva-calendar` — личный календарь, Google Calendar

| Команда или запрос | Результат |
| --- | --- |
| «Что сегодня?», «покажи завтра», «покажи неделю» | События, Брони, Распорядок; у дня — Свободные окна и пересечения |
| «Когда у меня два часа?» | Вид дня со Свободными окнами; отдельного поиска нет |
| «Запиши встречу», «создай Событие», встреча из Inbox | Событие с датой, временем и длительностью или на весь день; возможен повтор |
| «Перенеси», «измени» | Изменение выбранного События; у серии — одно вхождение, это и следующие или вся серия |
| «Удали», «отмени Событие» | Удаление выбранного События или части серии |
| «Добавь сон в календарь», «добавь Распорядок» | Регулярный блок поведения с устойчивым временем и длительностью |
| «Напомни за час», «убери напоминания» | Напоминания записи по предпочтению её типа или просьбе |
| «Покрась в Заряд», «перекрась неделю по схеме» | Цвет записи по смыслу занятия; новые записи красятся по схеме сами |
| «Смени календарь записи», «поменяй границы дня» | Ключ предпочтения и новое значение для Потребителя; по желанию — только в этом разговоре |
| Календарный сигнал для утра и Дневной проверки | Только то, что влияет на решение сейчас; только чтение |
| `status` | Предпочтения календаря и доступность инструментов |
| `help` | Справка по календарю без обращения к аккаунту |

Читаются выбранные личные календари Google, запись идёт в один календарь записи. Намерение без договорённости и встреча без даты — задача для `eva-tasks`. Привычка с реальной договорённостью по времени может иметь Событие, сама привычка остаётся в Habitify. Вне скилла: рабочий Outlook, RSVP, приглашения участников, напоминания по умолчанию самого календаря (меняются в Google Calendar), подготовка к встрече и итоги после неё, задания Ритма (их создаёт Потребитель).

## `eva-planning` — План дня, без своего провайдера

| Команда или запрос | Результат |
| --- | --- |
| «Спланируй день», «влезают ли дела» | Лента дня, Свободные окна, осторожный вердикт вместимости, один набор выборочных Броней |
| «Забронируй 14–16 на отчёт» | Бронь под выбранную задачу |
| «Не влезает», «перепланируй день» | Перенос или снятие будущих Броней; при нехватке времени — предложение сдвинуть задачи |
| «Почему так», «на чём это основано» | Основания Плана дня и их пределы |
| `status` | Доступность нужных скиллов, инструментов и предпочтений, без чтения содержимого аккаунтов |
| `help` | Команды, границы Плана дня и следующий шаг, без обращения к аккаунтам |

Планируется только день. Распорядок и События не ужимаются ради задач. Прошедшая или пропущенная Бронь не закрывает задачу. Длительность берётся из `timeLength`, иначе грубая оценка с «≈» без записи в задачу.

## `eva-notes` — Хранилище Obsidian

| Команда или запрос | Результат |
| --- | --- |
| Вопрос по базе: «что я знаю о…», «сравни…» | Ответ по Хранилищу со ссылками на Заметки; в Хранилище сохраняется только по просьбе |
| «Сохрани ссылку», «сохрани в базу», присланная ссылка или файл | Захват: статья полным текстом в Источники, файл — в Источники как есть; неясное и неизвлечённое — во Входящие хранилища; без разбора |
| «Разбери статью», конспект лекции, материал сообщества | План сущностей; запись только после ответа владельца |
| «Запиши мысль», «запиши идею» | Строка в заметке дня; личная идея — одна строка с `#идея`, рабочая — в `Работа/` Хранилища по её правилам; неясно, какая, — один вопрос |
| Дневник, запись о дне | Заметка дня за дату события в `eva.timezone`; время получения — отдельно |
| «Поправь idea-check», правка проектного скилла Работы | `eva-notes`: только файлы `Работа/_agents/skills/` Хранилища, после Preview и «Да»; не инструментами управления скиллами Hermes |
| «Покажи идеи» | Страница всех идей: строки с `#идея` из Дневника и развиваемые идеи; отдельная Заметка идеи — только когда владелец решил её развивать. Рабочие идеи — по правилам `Работа/` |
| Lint, «проверь вики» | Отчёт о проблемах вики; исправления — по просьбе |
| Массовая правка по явной просьбе | Вся правка сразу целиком, с проверкой и строкой в `log.md` |
| Заметка о привычке или проекте | Знания, контекст и ID объекта провайдера; обратная ссылка у провайдера — через `eva-habits` или `eva-tasks` |
| `status` | Доступность Хранилища, инструментов и встроенных скиллов; предпочтения Хранилища |
| `help` | Справка по Хранилищу без чтения Заметок |

Хранилище хранит знания, значимое о дне и ссылки на объекты провайдеров; задачи, Отметки и События остаются у провайдеров. После каждой записи — проверка файла и Отчёт: сделано, не проверено, не сделано; автоматического отката нет, откат — история Git Хранилища. Фоновые запуски в Хранилище пишут только Журнал Eva — папку `Eva/`; она не вики и не разбирается `eva-notes`. Путь к Хранилищу и его синхронизацию настраивает Потребитель.

## `eva` — карта, предпочтения, Журнал и Инициатива

«Что умеет Eva», «куда это записать», «какой скилл выбрать», «покажи все команды», «что такое Бронь» — справка без чтения аккаунтов; Журнал Eva навигатор ведёт сам. Глубокое уточнение намерения делает внешний `grill-me`, а не скилл Eva.

| Команда или запрос | Результат |
| --- | --- |
| «Запиши …» обычными словами | Место по смыслу: обязательство, действие или неясное — Inbox `eva-tasks`; идея — личная строкой с `#идея` в заметке дня, рабочая в `Работа/`, мысль или запись о дне — заметка дня, ссылка, файл, справка — захват; всё это — `eva-notes`. Затем строка, что и куда; владелец поправит словами |
| «Какие у меня предпочтения?» | Значения из блока `[Skill config …]`; `(not set)` — не задано |
| «Теперь рабочие дни вт–сб», любое изменение предпочтения | Ключ и новое значение для Потребителя, без сохранения; по желанию — только в этом разговоре |
| «Напоминай о weekly», «пришли сводку в 8:00» | Регулярные задания — Ритм — создаёт Потребитель; назвать, что ему передать |
| «Пусть ответ на утреннее сообщение продолжает разговор» | У названного задания Ритма — только `attach_to_session: true`; расписание, текст и доставку меняет Потребитель |
| «Вернись к этому через два часа», «вернись после обеда» | Возврат: разовое задание к Наблюдению, ответ придёт в этот чат; без `cronjob_manage` — срок в Журнале |
| «Что ты заметила?», «покажи Журнал» | Открытые Наблюдения со сроками и Практики из Журнала Eva |
| «Не предлагай Гвоздодёр до ноября», «реже», «больше не предлагай» | Ограничение практики в `Eva/Практики.md`; действует во всех разговорах и фоновых запусках |
| Ответ на сообщение Eva | Повод из Ленты, свежие данные, практика у её скилла; записи провайдерам — по их правилам |
| `status` | Предпочтения, корень Хранилища и наличие файлов Журнала, сегодняшние Инициативы и лимит, доступность `file`, `terminal`, `cronjob_manage` (toolset `cronjob`), `session_search`; без чтения аккаунтов |
| `help` | Что умеет Eva, Журнал и Инициатива обычными словами |

## Инициатива и Ритм — что Eva делает сама

Eva сама приходит с одной посильной практикой и фразой «зачем»; нечего сказать — молчит. Не больше `eva.initiative.daily_limit` Инициатив в день, только внутри границ дня. Фоновые запуски пишут только в Журнал Eva и ставят Возвраты; провайдерам и в заметки не пишут и ни о чём не спрашивают. Задания Ритма создаёт Потребитель.

| Когда | Что приходит |
| --- | --- |
| Рефлексия, в начале дня | Отдельное сообщение: одно–три Наблюдения за прошедший день с предложенным решением; нечего сказать — тишина |
| Утро | Одно сообщение «с чего начать»: Daily open, в день Weekly — Weekly, в первый Weekly месяца — ещё Когда-нибудь, наступившие Обзоры экспериментов |
| Дневная проверка, каждые 2–4 часа | Одна Инициатива по сигналу данных или сроку Наблюдения, обычно тишина |
| Закрытие дня | Обычно тишина; примерно раз в неделю Гвоздодёр, раз в две недели Выгрузка из головы, при остатках из хвостов или со Сроком сегодня-завтра — Daily close; напоминание о привычках, не отмеченных за день |
| Возврат | Возвращение к Наблюдению в назначенное время |
| В разговоре | Переход после практики (Daily open → План дня и другие) и Наблюдение в конце практики |
