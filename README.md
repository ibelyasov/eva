# Eva

Русскоязычные Agent Skill для Hermes Agent: что и как Hermes делает в личной жизни и работе владельца по методологии каждой темы. Сейчас это личная продуктивность — шесть скиллов:

- **`eva-tasks`** ведёт задачи в [SingularityApp](https://singularity-app.com) по методу «Джедайских техник» Максима Дорофеева и исследованиям работы с задачами: Capture, Выгрузка из головы, Triage, следующий шаг проекта, Daily open, Daily close, Гвоздодёр, Weekly и разбор Inbox debt. Фокус-лист составляется без календаря и проверки вместимости; разделы и теги поддерживаются, kanban — нет ([ADR 0007](docs/adr/0007-no-kanban.md)).
- **`eva-habits`** ведёт поведенческие эксперименты и ритуалы в [Habitify](https://habitify.me): план эксперимента в заметке привычки, отметки, помощь при тяге и обзоры. Ритуал объединяет привычки в Области Habitify; новое поведение проверяется одним экспериментом за раз. При признаках клинического риска Safety-стоп направляет к специалисту.
- **`eva-calendar`** ведёт личный Google Calendar: показывает день и неделю, создаёт, переносит и удаляет События, ведёт Распорядок по просьбе пользователя. Читает выбранные календари, пишет в один; рабочий Outlook не управляется.
- **`eva-planning`** составляет План дня поверх Фокус-листа: проверяет вместимость по свободным окнам и предлагает Брони для важных задач. Бронь ссылается на задачу, не закрывает её. Daily open остаётся в `eva-tasks`; План дня — следующий шаг после него.
- **`eva-notes`** ведёт Хранилище Obsidian владельца как вики знаний по методу LLM-wiki поверх встроенного скилла Hermes `llm-wiki`: сохраняет присланные ссылки, файлы и мысли, ведёт заметку дня с идеями, разделы сфер жизни, работы, обучения, сообществ и проектов и отвечает на вопросы по базе со ссылками на заметки. Агент — основной писатель: перед разбором материала он присылает План сущностей и пишет только утверждённое, слова владельца не переписывает. Заметки о привычках и проектах хранят знания и ссылку на объект, а План эксперимента, Отметки, статус и задачи остаются в Habitify и SingularityApp ([ADR 0018](docs/adr/0018-notes-over-llm-wiki.md)).
- **`eva`** всегда загружен: несёт компактную карту скиллов и предпочтения владельца из `skills.config`, которые читают остальные скиллы, ведёт Журнал Eva и Инициативу. По запросу объясняет возможности, словарь и карту команд, помогает выбрать скилл и следующий шаг; практики ведут доменные скиллы ([ADR 0011](docs/adr/0011-navigator-always-loaded.md)).

**Живая Eva.** Владельцу не нужно заранее знать сценарии и команды: Eva сама приходит в нужный момент с одной посильной практикой, одной фразой объясняет, зачем она, и ведёт её; если сказать нечего — молчит. Каждый день она разбирает прошедший день (Рефлексия), зовёт начать утро, несколько раз за день проверяет, не нужна ли помощь, и под конец работы предлагает короткую практику — обычно же молчит. Заметив проблему, Eva записывает Наблюдение и сама назначает себе Возврат к нему. Сообщения короткие: что сейчас важно, одно действие, зачем, сколько минут и какой фразой ответить; не больше `eva.initiative.daily_limit` в день и только внутри границ дня. Своё рабочее состояние — Пометки объектов, Наблюдения, историю практик и Ленту сообщений — Eva хранит в Журнале Eva, папке `Eva/` Хранилища Obsidian, где владелец видит и правит его. Ритм — задания cron — создаёт Потребитель по [SETUP.md](SETUP.md) ([ADR 0022](docs/adr/0022-eva-journal-and-initiative.md), [ADR 0006](docs/adr/0006-state-in-eva-journal.md)).

Решение всегда остаётся за пользователем. Полная явная команда выполняется сразу, включая несколько названных записей на разных провайдерах. Одиночное предложение агента — одна строка и «да»; собранный агентом набор — один общий Preview и подтверждение. Безвозвратная потеря данных Habitify (удаление привычки, области, удаление/отмена отметок) всегда требует однострочного подтверждения. Однозначное удаление События выполняется сразу: оно остаётся 30 дней в корзине Google, восстановление доступно только в интерфейсе Google. Группа выполняется последовательно, останавливается на первой ошибке с отчётом applied/unverified/unapplied и не откатывается автоматически. После каждой записи — Read-back ([ADR 0014](docs/adr/0014-confirmations.md)). В Хранилище явная просьба, включая массовую правку, выполняется сразу и целиком; разбор материала — только после ответа владельца на План сущностей; после каждой записи — проверка `read_file` и отчёт: сделано, не проверено, не сделано; откат — из истории Git Хранилища ([ADR 0019](docs/adr/0019-vault-write-consent.md)). Фоновые запуски пишут только в Журнал Eva и ставят Возвраты; провайдерам и в заметки Хранилища они не пишут и ни о чём не спрашивают ([ADR 0003](docs/adr/0003-no-unattended-writes.md)). Предпочтения задаются один раз при подключении ([ADR 0017](docs/adr/0017-declarative-preferences.md)). Термины — в [CONTEXT.md](CONTEXT.md), решения — в [docs/adr/](docs/adr/).

Проект в ранней версии. Версии — теги и commit SHA на [странице релизов](https://github.com/ibelyasov/eva/releases); публикация версии — отдельное решение владельца.

## Установка

Eva работает в [Hermes Agent](https://hermes-agent.nousresearch.com/) v0.21.6 или новее. Установка добавляет только инструкции шести скиллов. Доступ к SingularityApp, Habitify и Google Calendar, Хранилище Obsidian в песочнице, встроенные скиллы Hermes `llm-wiki` и `obsidian`, внешний скилл `grill-me`, предпочтения, настройки cron, задания Ритма и их модели Потребитель настраивает по [SETUP.md](SETUP.md). Ставьте закреплённую ревизию: полный 40-символьный commit SHA каждой версии указан на её [странице релиза](https://github.com/ibelyasov/eva/releases).

Каталог `skills/` закреплённой ревизии подключается в профильном `config.yaml` Hermes. Ревизию закрепляет источник каталога — checkout на нужном commit SHA или Nix input с этим SHA; у владельца так подключает clanwright.

```yaml
skills:
  external_dirs:
    - /path/to/eva/skills
  auto_load:
    - eva
  config:
    eva:      # значения — SETUP.md
```

**Только `eva-notes` в любом агенте.** `eva-notes` можно поставить отдельно прямо в Хранилище Obsidian для любого клиента Agent Skills — Claude Code, Codex, Gemini CLI, GitHub Copilot, Cursor, OpenCode, Goose — без Hermes и остальных скиллов. Дайте агенту ссылку на опубликованную версию Eva и попросите «установи только eva-notes»: он выполнит раздел отдельной установки `SETUP.md` этой версии — [раздел 10](SETUP.md#10-eva-notes-на-любом-агенте-agent-skills) ([ADR 0024](docs/adr/0024-portable-notes-skill.md)).

## Разработка

Правила для разработчиков и агентов — [AGENTS.md](AGENTS.md). Для локальной проверки скиллов укажите в `skills.external_dirs` каталог `skills/` своего checkout; изменения подхватываются в новом экземпляре агента Hermes.

Проверки из корня, без аккаунтов провайдеров:

```sh
git diff --check "$(git hash-object -t tree /dev/null)" HEAD  # всё дерево HEAD, как в CI
git diff --check HEAD                                         # незакоммиченные правки
```

[CI](.github/workflows/check.yml) проверяет пробелы во всём дереве HEAD против пустого дерева; остальное — независимое ревью. Штатного валидатора Hermes для каталога в `skills.external_dirs` нет, поэтому валидность frontmatter, security scan и discovery скиллов автоматически не проверяются ([ADR 0017](docs/adr/0017-declarative-preferences.md)). Доступ к провайдерам, поведение модели и выполнение операций проверки не подтверждают.
